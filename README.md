Пет-проект для изучения многопоточности

Представляет собой сервис для бронирования билетов на различные мероприятия.
Стэк
Java 17, Spring Boot 4.1.0, MVC с REST-эндпоинтами.

Первая проблема - параллельные запросы на бронирование дают успех, но по факту бронируется только то количество, которое доступно. Это race condition.
Эндпоинт /events/{id}/booking
